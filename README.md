## HTML
We used HTML as the backbone of our website because it lets us structure all the content in a clear and organized way. It gave us the framework to place text, images, links, and forms exactly where we needed them. By understanding HTML well, we could make sure the site was accessible, easy to navigate, and ready for styling and interactivity.

## CSS
CSS was essential for making our website look good and feel professional. We used it to style layouts, colors, fonts, and spacing, and AI helped us understand tricky concepts like flexbox and grid. It also helped autocomplete repetitive patterns without taking over the work, letting us experiment with designs while fully learning how styles interact and affect the page.

## JavaScript
We used JavaScript to add interactivity and dynamic features that make the website feel alive. From handling button clicks to updating content without refreshing the page, JS let us create a more engaging experience. AI helped us break down concepts like event handling and DOM manipulation so we could write clean, efficient code ourselves, making the site responsive and user-friendly.
